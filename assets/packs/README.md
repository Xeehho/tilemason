# 素材包说明

此目录存放你自己的素材包，**不会入库**（版权各自保留）。

推荐结构：

```text
assets/packs/<包名>/
├── tiles/        # 地面/道路/墙等规则方块（16px 网格 PNG）
├── props/        # 建筑/树木/摊位等独立物件（组装块 PNG，底边中心锚）
└── pack.json     # 素材清单（名称/分类/占格尺寸/锚点/连接规则，格式随 P0 落地）
```

约定：

- 默认 **16px 纹理网格**：规则方块按 16px 切片。
- 默认 **48px 组装块**：建筑/道具等独立物件按 48px 组装块对齐（3×3 网格）。
- 独立物件的锚点画在**底边中心**（PNG 本体在底边中心上方），y-sort 遮挡依赖此约定。
- 连接类素材（道路/墙）需要声明连接方向，供 P2 自动连接使用。
