## 阻断项 / 需要回测

### A. `map_view_probe` 资源泄漏（优先级 P1）

探针 47 条业务断言全部通过，但退出时原始输出报告：

```text
WARNING: 44 RIDs of type "CanvasItem" were leaked.
ERROR: 2 RID allocations of type '...DummyTextureE' were leaked at exit.
WARNING: ObjectDB instances leaked at exit.
ERROR: 3 resources still in use at exit.
```

现象出现在 `map_view_probe.gd` 创建 `MapView`/`view2` 并退出的路径；当前未据此断言正式运行时必然泄漏，但在项目规则“原始输出不得有未白名单泄漏”的标准下，本探针不能记为完全通过。

回测条件：补齐探针节点/纹理的生命周期清理，重新运行该探针；必须同时满足 47/47、退出码 0、无上述泄漏文本。随后再跑一次 CI 三关和全部探针，防止清理改动破坏视图断言。

### B. P1 新增交互缺少本轮可复现的 GUI 自动证据（优先级 P1）

以下功能已有代码提交和部分底层探针覆盖，但本轮没有专门的端到端交互脚本或用户重新操作记录，需手工回测：

- Ctrl+拖框矩形填充，覆盖/遇已有停止，以及一次撤销完整回滚；
- 选择、框选、16px 吸附拖动，物件与格块一起移动；
- Ctrl+C/V 复制粘贴（物件、格块、整组布局、撤销）；
- Delete 删除与撤销；
- L 直线工具预览、端点和锁定层行为；
- H 水平镜像且保持素材方向；
- 图层显隐、锁定、透明度滑杆与新建 Sprite 同步；
- Ctrl+O / Ctrl+Shift+S 文件对话框及当前文件语义；
- 自动保存、手动档丢失时自动恢复；
- Ctrl+A 全选物件与方块；
- 状态栏工具/素材/落层/锁定提示；
- Shift 临时单块放置不进入连续笔画。

建议手工回测时使用一份临时地图，逐项记录“操作前、操作后、撤销后、重做后”，并保留截图；不要用已有用户存档作为唯一证据。

### C. P1 未完成项

任务文件仍将“高层覆盖低层警示”列为未完成。当前状态栏已有锁定警示，但这不等同于画布上的覆盖关系视觉提示，不能验收为 design.md §4 已完成。

### D. P2 未进入验收

自动连接目前是预研记录：已有 `connections` 字段和道路/墙变体 intake，但尚未实现掩码匹配、落格后邻居刷新、橡皮擦后邻居刷新或 L/T 形截图证据。因此本轮不把 P2 计入通过项。

1. 先修复并复跑 `map_view_probe` 泄漏；确认无泄漏后重跑 CI 三关、4 个探针和截图取证。
2. 按上面的 P1 GUI 清单做一次用户窗口验收，重点是自动保存/恢复、文件对话框、复制粘贴、格块拖动和 Ctrl+A。

5. 只有阻断项清零、P1 手工清单有证据且用户确认后，再考虑 `v0.1.0` tag；本轮没有创建 tag。
