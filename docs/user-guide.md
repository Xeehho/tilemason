# TileMason 使用指南

TileMason 是一款 2D 像素地图拼装桌面工具：像搭积木一样用素材件拼出街道、建筑、庭院与室内，每个件都可编辑、可保存、可导出为运行时地图。本指南面向第一次上手的用户。

## 五分钟上手

1. **选素材**：右侧面板按分类浏览（地面/道路/墙体/建筑/树木/摊位…），点击缩略图选中；顶部搜索框可直接搜名字；数字键 1-7 快速取用底部快捷栏常用件。
2. **铺地面**：选「地面」分类的草地/泥土，在画布上按住左键拖动，铺出一片。
3. **修路**：选道路素材拖一条线——拐角会自动变成弯道、尽头自动收口（自动连接）。
4. **摆建筑**：选建筑/树木，左键放置——底座自动落在鼠标格上，半透明预览所见即所得，绿色框是它的占地范围。
5. **检查与保存**：F9 检查道路断没断、建筑堵没堵路；Ctrl+S 保存。下次打开自动恢复。

## 工具栏

窗口顶部左侧是图标工具栏：当前工具**金色高亮**，按了快捷键不确定自己在什么模式时看一眼即可。悬停图标会显示对应快捷键。点「画笔」图标可一键退出其他模式回到普通落笔。

## 图层

左侧图层面板（自上而下=从高层级到低层级，上面的盖住下面的）：

- **点层名**＝设为活动层（金色高亮）——之后放置的方块/物件优先落这一层；
- **双击层名**＝重命名；**⠿ 拖柄**拖到某行＝调整层级顺序；
- 底部 **+方块层 / +物件层** 随时新建自定义图层，**×** 删除空层（有内容的层需先清空，防误删）；
- 每行可勾选**显示/隐藏**、**锁定**（锁定后放不进也擦不掉）、拖**透明度**滑杆。

## 底部快捷栏

最左是**橡皮擦常驻格**（点击或按 E）；右侧 7 个素材槽纯图标显示——**点击**选用，**右键槽位**把它绑定成当前选中的素材（不选素材时右键＝清空该槽），绑定自动保存，下次打开不变。

## 素材包

工具自带一套演示素材（开箱可玩）。自己的素材放 `assets/packs/<包名>/`：`tiles/` 放 16px 规则方块、`props/` 放 48px 独立物件，`pack.json` 写清单（分类/锚点/占格/连接方向），详见 `assets/packs/README.md`。

## 导出

Ctrl+E 一键导出双形态：

- **运行时场景**（.tscn）：地面批渲染层 + 按底边锚摆放的物件层（自动排序遮挡），每件自带底边碰撞体与交互锚点；
- **结构化 JSON**（.export.json）：全部地图数据，可接入任意引擎/管线。

导出前自动跑地图检查，问题列在输出里，修完再导更放心。
