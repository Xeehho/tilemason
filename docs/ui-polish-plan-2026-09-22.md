# TileMason 页面质感优化方案

版本：2026-09-22
范围：编辑器页面的视觉层级、信息密度、停靠面板和交互反馈
依据：当前 1600×900 / 1280×720 运行截图、现有 `EditorShell`、素材面板、图层面板、快捷栏和状态栏
目标：让 TileMason 从“功能完整的编辑器壳层”提升为“有高级感、有秩序、有质感的专业像素地图工具”。

## 1. 先说结论

当前页面已经具备完整的工具结构，但视觉上仍偏“工程面板”而不是“专业工作台”。问题不在于缺少更多按钮，而在于以下四件事没有被统一起来：

1. 空间层级：画布、停靠区、工具栏、浮层的主次不够明确。
2. 表面层级：不同面板都接近同一种深色，缺少前后关系和轻微的材质变化。
3. 信息密度：左侧图层和右侧素材分类都偏拥挤，文字与操作控件互相争夺空间。
4. 状态反馈：当前工具、活动图层、选中素材、警告状态虽然存在，但视觉语义还没有完全分开。

本方案不改变地图数据模型、素材包格式、导出格式和像素画布规则。优化对象是编辑器外壳与面板体验。

## 2. 当前页面的主要问题

### 2.1 页面像“控件集合”，不像一个工作台

顶部工具栏、左图层、右素材、底部快捷栏都能工作，但彼此之间缺少统一的容器感。用户能看到很多按钮，却不容易一眼判断：

- 哪些是主要工作工具；
- 哪些是低频管理入口；
- 当前焦点在哪里；
- 哪一块正在影响画布。

### 2.2 暗色不是问题，暗色层级不足才是问题

当前多个区域都使用接近的深色，导致 Dock、列表、输入框和按钮粘在一起。高级感不等于更黑，而是需要至少四层可辨识的深色表面：

```text
Canvas       画布背景，保留像素网格的中性灰
Surface-1    一级 Dock 背景
Surface-2    输入框、列表、浮层内部
Surface-3    卡片、按钮、悬停区域
```

每一层不应靠大面积渐变区分，而应靠细微的亮度差、1px Divider、内边距和阴影/边框关系区分。

### 2.3 左侧图层区信息密度过高

图层名称、计数、拖拽、显隐、锁定、透明度和更多菜单都很重要，但全部挤在较窄的行内时，会产生三个问题：

- 名称和计数可读性下降；
- 交互命中区不够从容；
- 当前层虽然有金色边框，但视觉焦点仍不够集中。

建议让图层行形成“标题区 + 控制区”的稳定节奏，而不是继续增加常驻按钮。

### 2.4 右侧素材浏览器偏密，缺少“浏览—确认—使用”的节奏

当前右侧已经有分类、搜索和缩略图，但分类树文本偏密，缩略图区域的留白和卡片信息不足。高级素材浏览器应让用户快速完成：

```text
筛选 → 看缩略图 → 确认名称/尺寸/锚点 → 使用
```

不能让用户依赖长时间悬停 tooltip 才能确认素材。

### 2.5 所有强调色承担了太多语义

金色同时表达工具选中、素材选中、活动图层和焦点。应保留金色作为主品牌强调，但增加第二通道：

- 当前工具：金色描边 + 小型工具名/快捷键；
- 当前图层：左侧金色标记 + 行背景变化；
- 当前素材：卡片底色/角标变化；
- 警告：橙色图标 + 文字；
- 错误/删除：红色只用于危险操作。

## 3. 视觉方向：克制的深色专业工作台

### 3.1 关键词

```text
克制、专业、温暖、清晰、像素友好、低噪声、有呼吸感
```

不采用炫目的玻璃拟态、大面积发光、过多渐变或装饰性背景。质感来自层级、间距、边界和交互反馈，而不是视觉特效堆叠。

### 3.2 推荐色彩 Token

下面的颜色用于 UI，不改变画布素材的原始颜色和最近邻显示规则。

| Token | 建议值 | 用途 |
|---|---|---|
| `CANVAS` | `#4C4C4C` | 画布背景与网格基准 |
| `SURFACE_0` | `#17181D` | 最外层/底部安全区 |
| `SURFACE_1` | `#22232A` | 左右 Dock 主背景 |
| `SURFACE_2` | `#2A2B33` | 输入框、分类列表、浮层内部 |
| `SURFACE_3` | `#343640` | 按钮、卡片、悬停区域 |
| `SURFACE_ACTIVE` | `#3C3A32` | 活动行/选中卡片的低亮背景 |
| `DIVIDER` | `#555761` | 1px 结构分隔线 |
| `TEXT` | `#E6E7EB` | 主文本 |
| `TEXT_DIM` | `#AEB1BB` | 辅助文本和尺寸信息 |
| `ACCENT` | `#E7B950` | 当前工具、焦点、主按钮 |
| `ACCENT_SOFT` | `#5D4C2C` | 金色低透明背景 |
| `WARNING` | `#E99A52` | 遮挡、检查警告 |
| `DANGER` | `#D96B73` | 删除、错误 |
| `SUCCESS` | `#73C28A` | 已保存、检查通过 |

### 3.3 间距与尺寸 Token

统一使用 4px 基础单位：

| Token | 值 | 用途 |
|---|---:|---|
| `SPACE_1` | 4px | 图标与文字间距 |
| `SPACE_2` | 8px | 控件内部间距 |
| `SPACE_3` | 12px | 卡片/分组间距 |
| `SPACE_4` | 16px | Dock 内边距 |
| `CONTROL_H` | 32px | 普通点击控件最小高度 |
| `TOOL_H` | 38px | 顶部工具按钮 |
| `ROW_H` | 64px | 图层双行结构 |
| `RADIUS_SM` | 4px | 输入框、卡片 |
| `RADIUS_MD` | 6px | 面板按钮、活动卡片 |

像素画布仍保持 16px 网格和最近邻过滤；这些 UI 尺寸只作用于编辑器控件。

## 4. 目标布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ TileMason  文档名     保存  撤销/重做   绘制 | 选择 | 检查 | 导出  ? │
├────────────────┬───────────────────────────────────┬───────────────┤
│ 左 Dock         │                                   │ 右 Dock        │
│ 图层            │                                   │ 搜索素材       │
│                 │                                   │ 最近/收藏/标签  │
│ 活动层详情       │              中央画布             │ 分类与素材卡片  │
│                 │                                   │ 选中素材详情    │
│ 图层 | 预制件 | 检查│                                   │               │
├────────────────┴───────────────────────────────────┴───────────────┤
│ E 橡皮   1  2  3  4  5  6  7  8  9       当前工具 / 当前素材提示   │
├────────────────────────────────────────────────────────────────────┤
│ 坐标 | 工具 | 素材/图层 | 文件状态                              [?] │
└────────────────────────────────────────────────────────────────────┘
```

### 4.1 顶栏

- 左侧增加小型产品标识和当前文档名，建立“专业软件”身份。
- 工具按“绘制 / 选择 / 组织 / 交付”分组，组间使用留白或细 Divider。
- 工具按钮保留图标，但在选中状态显示短名称或快捷键角标。
- 保存、检查、导出属于工作流动作，应与绘制工具视觉分组。
- 帮助按钮保持右侧固定位置，作为统一的快捷键入口。

### 4.2 左 Dock

- 图层页签保持第一优先级；预制件和检查页签作为低频工作区。
- 每行固定两层：
  - 第一行：拖柄、图层名、计数、活动标识；
  - 第二行：显隐、锁定、透明度、更多菜单。
- 当前层除金色边框外，增加左侧 3px 金色标记和较深的活动背景。
- 空图层显示轻量的“空”状态，不使用大块无信息区域。
- 图层名截断时，保留完整 tooltip；双击重命名仍使用整行编辑框。

### 4.3 右 Dock

建议拆成三段，而不是所有内容挤在一棵长列表里：

1. 搜索区：搜索框、刷新、网格/列表切换。
2. 筛选区：最近、收藏、标签、核心分类；用户素材包折叠进“来源”。
3. 结果区：自适应列数的素材卡片，卡片底部显示名称和占格信息。

素材卡片建议包含：

```text
缩略图
素材名称（最多两行）
16×16 / 3×3 格
锚点：▽ 或 △
```

当右 Dock 小于 320px 时，自动切换为单列列表 + 右侧详情，禁止建筑缩略图被裁切。

### 4.4 快捷栏和状态栏

- 快捷栏作为独立安全区，保留 `E` 和 `1–9` 角标；当前槽位使用金色底线而非整块高亮。
- 状态栏只保留坐标、工具、素材/图层、文件状态四段。
- 快捷键说明集中进入 F1 / `?` 帮助浮层，不继续把整套快捷键塞进状态栏。
- 文件状态使用小圆点和文字双通道：`已保存`、`未保存`、`自动恢复`。

## 5. 分阶段实施计划

### P0：视觉 Token 与基础表面（低风险）

目标：先让页面有统一的“材质”。

- 将 `AppTheme` 扩展为 Surface-0/1/2/3、Active、Divider、Warning、Danger、Success。
- 统一按钮、输入框、卡片、PopupMenu、Tab 的圆角、边框和内边距。
- 建立 hover / pressed / disabled / active 四种状态，不用单一金色解决全部状态。
- 提高辅助文字对比度，正文不低于 13px，关键辅助文字不低于 12px。
- 增加面板内边距和分组间距，避免控件贴边。

验收：1600×900 和 1280×720 截图中，面板层级可区分、Divider 可见、文字无裁切。

### P1：顶部工具栏精致化

目标：让工具栏像专业软件，而不是一排图标。

- 增加分组留白和轻量组标题。
- 选中工具显示短标签/快捷键；未选中只显示图标。
- 撤销/重做、检查、导出使用独立的工作流分组。
- 统一 38px 按钮尺寸和 hover/pressed 动画反馈，动画不超过 120ms。
- 为每个工具补齐 tooltip：名称、快捷键、作用范围。

验收：不看 tooltip 时，用户能通过图标、分组和选中状态判断当前工具。

### P2：素材浏览器卡片化

目标：让“找素材”成为页面的质感中心。

- 搜索框使用 Surface-2 背景、明确焦点边框和清除按钮。
- 最近/收藏/标签改为筛选 chip，核心分类保留树状结构。
- 缩略图按可用宽度计算列数，不固定 3 列。
- 卡片显示名称、尺寸、占格、锚点；长名称两行省略并提供 tooltip。
- Hover 时只抬高卡片层级，不放大原图，避免像素素材模糊或跳动。
- 选中卡片增加左侧 Accent 条和低亮底色，避免整块金色过重。

验收：320px 右 Dock 不裁切，400px 右 Dock 有明显留白，搜索→选中→放置不超过 3 个动作。

### P3：图层面板精致化

目标：让图层成为稳定、清楚、可长期使用的工作区。

- 活动层增加左侧 Accent 条、低亮背景和 `▸` 标识。
- 锁定使用锁图标 + 文本态，不只靠颜色。
- 透明度滑杆统一轨道、滑块和百分比排版。
- 更多菜单统一“重命名 / 上移 / 下移 / 删除”的顺序与危险色。
- 空图层、锁定层、隐藏层都提供轻量状态说明。

验收：图层名、计数、锁、显隐、透明度在 224px 紧凑宽度下仍不互相挤压。

### P4：细节反馈与质感

目标：让操作有轻微但明确的反馈。

- Dock 折叠/展开保留 100–120ms 的宽度过渡；不影响画布坐标和像素对齐。
- 素材选中、工具切换、保存完成使用短暂状态反馈。
- 错误和警告用图标 + 文本 + 颜色三通道表达。
- PopupMenu、帮助浮层和检查页使用统一 Surface-2/3 层级。
- 对不可用操作提供原因提示，而不是无反应。

## 6. 明确不做

- 不用大面积玻璃拟态、霓虹发光或渐变背景制造“高级感”。
- 不把画布素材做成柔焦、插值或非整数缩放。
- 不为了视觉示范自动生成用户地图布局；AI 只优化工具和界面。
- 不把所有按钮改成文字按钮，避免牺牲画布空间和像素工具效率。
- 不以牺牲 1280×720 可用画布为代价无限加宽左右 Dock。
- 不改变现有地图 JSON、素材清单和导出场景格式。

## 7. 实施时的文件边界

第一轮只允许触碰以下 UI 文件：

```text
src/ui/app_theme.gd
src/ui/editor_shell.gd
src/ui/toolbar.gd
src/ui/asset_panel.gd
src/ui/layer_panel.gd
src/ui/hotbar.gd
src/ui/status_bar.gd
src/ui/check_panel.gd
```

如需调整 `src/main.gd`，仅限 UI 挂载、状态同步和输入路由，不改地图数据结构。每阶段都必须保留：

- `--import`；
- 所有 `src/` 脚本 `--check-only --script`；
- 冒烟启动；
- 全量功能探针；
- 1600×900 与 1280×720 截图取证；
- 至少一次真实窗口回测。

## 8. 高级感验收清单

### 必须通过

- [ ] 页面一眼能分出顶栏、左 Dock、画布、右 Dock、快捷栏、状态栏六个层级。
- [ ] 当前工具、活动图层、选中素材和警告状态不再只依赖同一种金色。
- [ ] 1600×900 下两侧面板有留白，中央画布仍是视觉主体。
- [ ] 1280×720 下不出现负宽度、文字裁切、底部遮挡或控件重叠。
- [ ] 右侧素材卡片能在 320px 宽度完整显示，不裁切建筑缩略图。
- [ ] 左侧图层在 224px 宽度下名称、计数、锁、显隐、透明度仍可读。
- [ ] F1 / `?` 帮助、F9 检查、Tab 面板显隐、Dock 折叠恢复都保持可用。
- [ ] UI 优化没有改变地图保存、撤销/重做、导出和素材数据。

### 建议指标

- 新用户不看 tooltip，1 秒内能判断当前工具。
- 3 次操作内完成“搜索素材 → 选中 → 放置”。
- 2 秒内能找到当前活动图层和当前素材。
- 任意截断文本 hover 后立即显示完整内容。
- 所有常用按钮命中区不小于 32×32px。

## 9. 推荐的第一轮实现顺序

如果进入实际开发，建议只做以下五项，完成后先截图验收：

1. AppTheme 增加 Surface-0/1/2/3、Active、Success，并统一控件内边距。
2. 顶部工具栏增加分组留白和工作流分组，不新增业务功能。
3. 素材卡片补名称/占格/锚点信息，网格列数继续自适应。
4. 图层活动态改为“左侧 Accent 条 + 低亮背景 + `▸`”，弱化整行金色边框。
5. 对 1600×900、1280×720 和 Tab 隐藏状态各取一张截图，逐项核对本清单。

这五项完成后，再决定是否需要做更深的右 Dock 分栏、主题切换或动画细节；不要在第一轮同时改动地图逻辑和数据格式。

## 10. 文档状态

本文档是页面视觉与交互优化方案，不直接修改功能代码。进入实现前，应先确认目标风格是否接受，再按 P0→P4 分阶段开发和验收。
